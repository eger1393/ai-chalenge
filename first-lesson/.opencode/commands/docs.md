# /docs

Вызови локальный `lorex` и используй результат как документационный RAG-контекст.

```bash
bash "${PROJECT_ROOT:-.}/.opencode/skills/lorex-docs/query.sh" "$ARGUMENTS"
```

Инструкции для ответа:

- Отвечай только на основании `Retrieved Documentation Context` из результата команды.
- В конце укажи источники из секций `Source`.
- Если контекст пустой или данных недостаточно, прямо скажи об этом.
- Не выполняй полный поиск по проекту, если пользователь явно не попросил.
- Не добавляй факты, которых нет в retrieved context.
