# E2E Scenario: Конфигурируемые параметры AI запросов

Платформы: Backend, Web

## Шаги

### Backend
- [x] 1. Backend компилируется без ошибок (npm run build) ✅ (проверено)
- [x] 2. POST /api/chat/message принимает params объект (температура, maxTokens, stop, systemPrompt) ✅ (проверено)
- [x] 3. POST /api/chat/message без params работает как раньше (обратная совместимость) ✅ (проверено)
- [x] 4. Ответ содержит appliedParams с реально примененными значениями ✅ (проверено)

### Frontend
- [x] 5. Frontend компилируется без ошибок (npm run build) ✅ (проверено)
- [x] 6. На странице чата появилась иконка gear рядом с полем ввода ✅ (проверено)
- [x] 7. Клик по gear открывает/закрывает панель параметров ✅ (проверено)
- [x] 8. Панель содержит: temperature slider, max_tokens input, stop sequences, system prompt textarea ✅ (проверено)
- [x] 9. Изменение параметров сохраняется (перезагрузка страницы не сбрасывает) ✅ (проверено)
- [x] 10. Отправка сообщения с нестандартными параметрами — перед ответом отображаются примененные параметры ✅ (проверено)
- [x] 11. Кнопка Reset сбрасывает все параметры к дефолтам ✅ (проверено)
- [x] 12. При дефолтных параметрах метаданные не отображаются перед ответом ✅ (проверено)
