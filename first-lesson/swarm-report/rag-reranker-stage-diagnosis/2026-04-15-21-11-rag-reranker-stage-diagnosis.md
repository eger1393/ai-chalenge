# Отчёт: диагностика RAG reranker на stage

## Задача

Проверить stage-логи, почему при включённом `RAG` пользователь почти на любой
вопрос получает сообщение, что релевантные фрагменты не прошли порог отбора.

## Что проверено

- Логи `backend` на stage за последние 30 минут
- Полные RAG trace-id с расширенным логированием
- Прямой вызов текущей reranker-модели внутри stage-контейнера на английских и
  русских парах `query + text`

## Вывод

Проблема не в vector search и не в similarity-порогах.

- Vector search стабильно находит релевантные кандидаты с similarity около
  `0.51 .. 0.57`
- Все кандидаты отваливаются на этапе `reranker`
- Для русских запросов текущая модель `Xenova/bge-reranker-base` выдаёт почти
  нулевые оценки `0 .. 0.0022`
- Из-за этого все фрагменты режутся по `reranker_score_below_threshold`

## Доказательства

### Trace `rag-mo0d3qet-mtyg2i`

- Запрос: `что автор знает о мире Гарри Поттера?`
- Vector search: кандидаты с similarity до `0.5735`
- Reranker: оценки `0`, `0.0001`, `0.0005`
- Итог: `selectedCount = 0`

### Trace `rag-mo0d5ox8-a8ajjl`

- Вопрос по `Claude Code`
- Vector search: кандидаты с similarity до `0.5694`
- Reranker: оценки `0`, `0.0003`, `0.0006`, максимум `0.0022`
- Итог: `selectedCount = 0`

### Прямая проверка модели внутри контейнера

- Английская релевантная пара `Harry Potter` / `Harry Potter` дала логит
  `8.8426`
- Английская релевантная пара `Harry Potter world` / `Harry Potter and Hogwarts wizard world`
  дала логит `1.5167`
- Русская релевантная пара `что автор знает о мире Гарри Поттера?` /
  `Автор подробно обсуждает Гарри Поттера и Роулинг.` дала логит `-10.1963`
- Русская пара `что автор знает о мире Гарри Поттера?` /
  `Гарри Поттер и философский парень` дала логит `-9.2245`

## Корневая причина

Текущая модель reranker практически непригодна для русскоязычного корпуса и
русских запросов. Для английских пар она даёт адекватные логиты, для русских
почти всегда уходит глубоко в отрицательную область.

## Рекомендация

- заменить `Xenova/bge-reranker-base` на совместимую многоязычную модель
- до замены не полагаться на режим `reranker` для русского корпуса

## Ограничения и допущения

- Дополнительно в stage-логах остаётся отдельная проблема MCP:
  `Unknown MCP tool: github-explorer__list_subscriptions`
- Эта диагностика не меняет runtime и не исправляет проблему сама по себе
