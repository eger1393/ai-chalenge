# Отчёт по задаче: контрольные вопросы для RAG

## Статус

Готово

## Краткое описание задачи

Составить мини-набор из 10 контрольных вопросов для проверки RAG по Telegram-дампу, зафиксировать ожидание от ответа и ожидаемые источники.

## Что выполнено

- По stage `chatdb` проверен диапазон RAG-индекса:
  - `6579` документов
  - период с `2022-03-15` по `2026-04-14`
- Из `rag_documents` отобраны темы с устойчивыми источниками:
  - продукт и процесс
  - признание ошибок
  - Odyssey
  - ОС Аврора
  - Kotlin in Practice
  - ИИ-агенты
  - рынок труда
  - стоимость ИИ-инструментов
- Создан контрольный документ `RAG_CONTROL_QUESTIONS.md`
- В `PROJECT_MAP.md` добавлена ссылка на новый контрольный документ

## Проверки

- `RAG_CONTROL_QUESTIONS.md` перечитан после создания
- `PROJECT_MAP.md` проверен на наличие новой записи
- `git diff --check -- RAG_CONTROL_QUESTIONS.md PROJECT_MAP.md` — успешно

## Ограничения и допущения

- Источники указаны как `rag_documents.external_id`, то есть ID сообщений из Telegram-дампа
- Набор ориентирован на ручную и полуавтоматическую проверку качества retrieval и ответа, а не на автоматический benchmark
