# Усиление Query Rewrite Для RAG

## Задача

Сделать текущий `query rewrite` заметно полезнее для разговорных русских запросов, не меняя архитектуру и не добавляя кодовые эвристики.

## Что реализовано

- Ужесточён контракт `query rewrite` в `backend/src/rag/rag-query-rewrite.service.ts`
- Модель теперь обязана возвращать JSON с полями:
  - `query`
  - `applied`
  - `reason`
- Валидация ответа стала fail-fast:
  - `applied=true` при неизменённом запросе считается ошибкой
  - `applied=false` при изменённом запросе считается ошибкой
  - `reason` обязан входить в фиксированный список допустимых значений
- Prompt теперь явно требует:
  - нормализовать разговорный русский и сленг
  - канонизировать имена сущностей вроде `Claude Code`
  - переводить вопросы в retrieval-friendly формулировку
- В debug и логах добавлены:
  - `reason`
  - `rawApplied`
- На фронте в debug-панели теперь отображается причина `rewrite` или `no-op`
