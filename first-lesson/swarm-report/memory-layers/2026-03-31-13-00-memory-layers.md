# Фича: 3-уровневая память

Дата: 2026-03-31  
Статус: **Done**

## Описание задачи

Реализация расширяемой 3-уровневой памяти для чат-приложения:
1. **Краткосрочная (short-term)** — текущие сообщения диалога (conversation). Существовала ранее.
2. **Рабочая (working)** — задача (Task) с описанием. Диалоги привязываются к задачам.
3. **Долговременная (long-term)** — профиль пользователя: язык, стиль, краткость, кастомный промпт.

## Research (консилиум)

- **Архитектор:** `MemoryAssemblerService` ДО стратегий контекста. Стратегии не трогать.
- **Фронтенд-эксперт:** Персонализация — только сервер (не localStorage). Аккордеон задач в сайдбаре.
- **UI-дизайнер:** Цвета уровней: purple/amber/sky. Вкладки в правом drawer.
- **API-дизайнер:** task_id не передаётся в /chat/message — бэкенд берёт из conversation.task_id.

## Архитектурные решения

- **MemoryAssemblerService** — единственная точка сборки. Для 4-го уровня — добавить блок в один метод.
- **Порядок в systemPrompt:** `[LONG-TERM] → [WORKING] → [SHORT-TERM]` через `---` разделитель.
- **Стратегии контекста не изменены** — продолжают получать systemPrompt как строку.
- **task_id в /chat/message не передаётся** — бэкенд сам берёт из `conversation.task_id`.
- **Персонализация только на сервере** — не в localStorage, чтобы работало между устройствами.
