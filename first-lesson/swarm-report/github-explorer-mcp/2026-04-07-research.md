## Сводка консилиума

### Архитектор

**Подход:** кастомный Node.js/TS MCP-сервер (stdio) + supergateway для Streamable HTTP. Единообразие с postgres-mcp.

**Структура:**
```
github-explorer-mcp/
├── Dockerfile
├── entrypoint.sh
├── package.json
├── tsconfig.json
└── src/
    ├── index.ts              # MCP Server, регистрация тулов, stdio transport
    ├── github-api.ts         # HTTP-клиент GitHub REST API (native fetch)
    ├── tools/
    │   ├── search-repos.ts
    │   ├── get-description.ts
    │   ├── list-branches.ts
    │   └── get-commits.ts
    └── utils/
        └── parse-repository.ts
```

**Инфраструктура:**
- Порт: 8097 (внутренний, docker-сеть)
- Env: `MCP_GITHUB_EXPLORER_URL=http://github-explorer-mcp:8097/mcp`
- Зависимости: `@modelcontextprotocol/sdk` + `supergateway` (global)
- Нулевая зависимость от backend

**Риски:**
- Rate limit 60 req/h — информативные ошибки, заложить точку расширения для токена
- Порядок запуска — depends_on в docker-compose
- User-Agent header обязателен для GitHub API

### Фронтенд-эксперт

**Изменения минимальны.** Единственный файл: `pipeline-message-bubble.tsx` — добавить `github-explorer` в `SERVER_COLOR_MAP` и `SERVER_ICON_MAP` (строки 30-31).

Debug-panel, message-bubble, use-pipeline — изменений не требуют.

Рекомендация на будущее: передавать icon/color динамически с бэкенда (не блокер).

### UI-дизайнер

**Конфигурация mcp-servers.json:**
- displayName: "GitHub Explorer"
- icon: "globe" (свободна, семантически подходит)
- color: "purple" (контрастен с blue/postgres, ассоциация с GitHub)

**Визуализация:** специальные компоненты для GitHub не нужны. ToolCallCard — универсальный. LLM сам форматирует ответ.
