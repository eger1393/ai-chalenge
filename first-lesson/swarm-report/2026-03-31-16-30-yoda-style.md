# Фича: Стиль диалога "Мастер Йода"
Дата: 2026-03-31

## Описание задачи
Добавить стиль диалога "Мастер Йода" в систему персонализации ChatGPT-клиента.

## Итоги Research
Консилиум из 4 агентов (Архитектор, Фронтенд-эксперт, UI-дизайнер, API-дизайнер) определил:
- Нужно изменить 4 файла (2 backend, 2 frontend)
- Миграции БД не требуются (dialogue_style — VARCHAR(30))
- Паттерн добавления нового стиля прост: type + label + массив + DTO + styleMap

## План
1. Backend DTO: добавить 'yoda' в @IsIn и union type
2. Backend memory-assembler: добавить промпт для стиля Йоды в styleMap
3. Frontend types: добавить 'yoda' в DialogueStyle и STYLE_LABELS
4. Frontend UI: добавить 'yoda' в массив STYLES + col-span-2 для нечётного элемента
