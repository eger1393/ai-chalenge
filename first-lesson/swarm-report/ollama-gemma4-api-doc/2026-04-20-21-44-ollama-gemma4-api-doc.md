## Проверка

Проверены реальные запросы через текущий публичный адрес:

- `POST /api/chat` с `think: true`
- `POST /api/chat` с `tools`
- `POST /api/chat` с `format: "json"`
- `GET /api/ps`
- `GET /v1/models`
- `POST /v1/chat/completions`

Дополнительно сверено с официальной документацией `Ollama` и страницей `gemma4` в библиотеке моделей.
