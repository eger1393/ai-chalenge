# Отчёт по задаче: рекомендация локальной LLM для `RTX 4090`

## Краткое описание задачи

Определить, какой рантайм лучше выбрать для удалённой GPU-машины с
`NVIDIA GeForce RTX 4090`, и какую современную локальную модель имеет смысл
запускать как основной вариант.

## Фактический контекст

- Хост: `superlook-gpu-dev` (`ubuntu-server`)
- GPU: `NVIDIA GeForce RTX 4090`
- VRAM: около `24 ГБ`
- RAM: около `31 ГБ`
- На хосте есть `python3` и `docker`
- На хосте отсутствуют `ollama` и `vllm`

## Рекомендация по рантайму

Для этого сервера лучший дефолтный выбор — `Ollama`.

Причины:

- на headless Linux-сервере он проще, чем `LM Studio`
- он уже имеет официальный каталог готовых локальных моделей
- под него официально доступны `Gemma 4`, `Qwen3` и `Mistral Small 3.1`
- он даёт простой локальный HTTP API без лишней настройки

Когда выбирать другие варианты:

- `vLLM` — если нужен именно серверный OpenAI-совместимый API с упором на
  throughput и интеграцию в backend
- `LM Studio` — если работа идёт на desktop-машине с GUI, а не на удалённом
  Linux-хосте по SSH
- `llama.cpp` — если нужен тонкий ручной контроль над квантизацией,
  offload-настройками и низкоуровневым инференсом

## Рекомендация по модели

Основная рекомендация по состоянию на `20 апреля 2026 года` —
`Gemma 4 31B`.

Почему именно она:

- Google выпустил `Gemma 4` `2 апреля 2026 года` как наиболее сильное открытое
  семейство моделей на текущий момент
- `Gemma 4 31B` позиционируется как старшая локальная workstation-модель
- по официальной оценке Google, `Gemma 4 31B` требует около `17.4 ГБ` в
  `Q4_0`
- в каталоге `Ollama` модель `gemma4:31b` опубликована как `20 ГБ`, что
  укладывается в `RTX 4090 24 ГБ`

Практический вывод:

- если нужен лучший общий баланс качества для reasoning, кода, агентных
  сценариев и обычного диалога, сначала запускать `gemma4:31b`
- это лучший основной кандидат для данной машины

## Альтернативы

- `mistral-small3.1:24b`
  Хороший вариант, если важнее скорость и более лёгкий запуск. Mistral
  официально заявляет, что модель работает на одной `RTX 4090`.
- `qwen3:30b-a3b`
  Сильная альтернатива, особенно если важны код, инструментальные сценарии и
  reasoning-режимы. Для локального запуска сам Qwen рекомендует `Ollama`,
  `LM Studio` и `llama.cpp`.

## Ограничения

- `Gemma 4 31B` нормально помещается в память в квантизованном варианте, но
  огромный контекст всё равно будет дополнительно съедать VRAM за счёт
  KV-cache
- `256K` контекст из модельного паспорта не означает, что он будет одинаково
  комфортен на `24 ГБ` во всех рантаймах
- если нужен именно серверный API под приложение, технологически сильнее может
  оказаться `vLLM`, но как первый практический старт он сложнее `Ollama`

## Итог

- Лучший рантайм по умолчанию для этого хоста: `Ollama`
- Лучшая модель, которую стоит пробовать первой: `gemma4:31b`
- Лучший запасной вариант: `mistral-small3.1:24b`
