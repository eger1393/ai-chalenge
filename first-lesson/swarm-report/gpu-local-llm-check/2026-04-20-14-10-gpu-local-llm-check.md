# Отчёт по задаче: проверка видеокарты и подбор локальной LLM

## Краткое описание задачи

Проверить установленную видеокарту на локальной машине и определить, какие
современные локальные LLM-модели разумно запускать на этом железе.

## Что проверено

- GPU: `NVIDIA GeForce RTX 2070`
- VRAM: `8 ГБ`
- Драйвер NVIDIA: `591.86`
- CUDA Version: `13.1`
- Оперативная память: около `16 ГБ`
- Текущее использование VRAM в момент проверки: около `2 ГБ`
- `Ollama` в текущем окружении не установлен

## Вывод

Комфортный класс моделей для этой машины — современные `4B` и `8B` модели в
`4-bit` / `Q4` квантизации.

Практически рекомендованы:

- `Gemma 4 E4B` в `Q4`
- `Qwen3 4B`
- `Qwen3 8B` при умеренном контексте и после освобождения части VRAM
- `Ministral 3 3B`
- `Ministral 3 8B` как пограничный вариант

Неразумно для постоянной локальной работы на этой видеокарте:

- плотные `12B+` и `14B+` модели
- крупные reasoning/MoE-модели без сильной CPU-offload-схемы
- длинный контекст на `8B` моделях при уже занятой видеопамяти

## Результаты проверки

- Локальная диагностика железа выполнена успешно
- Актуальные открытые модельные семейства сверены по официальным источникам
- Для `Gemma 4` подтверждены официальные ориентиры по памяти

## Ограничения и допущения

- Оценка совместимости для `Qwen3` и `Ministral 3` дана по классу модели,
  размеру параметров и типичной практике запуска в GGUF/AWQ-квантизации
- Фактическая скорость и потолок по контексту зависят от рантайма
  (`llama.cpp`, `LM Studio`, `Ollama`, `vLLM`) и от того, сколько VRAM занято
  системой в момент запуска
- Тестовый запуск конкретной модели на этой машине в рамках задачи не
  выполнялся
