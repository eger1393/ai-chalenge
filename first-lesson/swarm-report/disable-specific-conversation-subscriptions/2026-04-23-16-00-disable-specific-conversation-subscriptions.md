# Отчёт: disable-specific-conversation-subscriptions

- Дата: `2026-04-23 16:00`
- Статус: `Готово`

## Краткое описание задачи

Отключить на фронтенде вызов ручки `/api/conversations/312c5b9e-1335-4107-91b9-fb4e0f270106/subscriptions`.

## Что сделано

- В `frontend/src/hooks/use-subscriptions.ts` добавлен точечный guard по `conversationId`.
- Для `312c5b9e-1335-4107-91b9-fb4e0f270106` хук больше не вызывает `getConversationSubscriptions()`.
- Вместо этого фронтенд просто выставляет пустой список подписок.

## Почему так

- Решение сделано на уровне `useSubscriptions`, а не в конкретном компоненте.
- Это гарантирует, что ни один фронтовый consumer этого hook не дёрнет данный endpoint для этого диалога.

## Валидация

- Сборка фронтенда не запускалась по прямому указанию пользователя.
