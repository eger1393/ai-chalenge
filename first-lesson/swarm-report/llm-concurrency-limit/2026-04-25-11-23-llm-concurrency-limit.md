# Отчёт: llm-concurrency-limit

## Задача

Добавить ограничение на количество одновременных вызовов нейросетей в backend: не больше `3` одновременно.

## Что реализовано

- В `backend/src/ai/openai.service.ts` добавлен глобальный in-memory лимит `3` одновременных LLM-вызова на весь backend-процесс
- Все основные пути вызова теперь используют общий слот:
  - `callOpenAI`
  - `callOllamaNativeChat`
  - `callOpenAIStream`
  - `callOpenAIStreamWithTools`
  - `callOllamaNativeChatStream`
- При превышении лимита новые запросы не стартуют параллельно, а ждут освобождения слота в очереди
- В логах добавлены сообщения о захвате слота, ожидании из-за лимита и освобождении слота

## Проверка

- Выполнен `npm run build` в `backend`

## Ограничения и допущения

- Лимит сейчас фиксированный и захардкожен в коде как `3`
- Лимит действует на один экземпляр backend-процесса; при нескольких репликах общий кластерный лимит будет равен сумме лимитов по репликам
- Очередь ожидания in-memory и не переживает рестарт процесса
