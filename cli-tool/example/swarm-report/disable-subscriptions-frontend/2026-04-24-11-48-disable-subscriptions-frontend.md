# Отчёт: disable-subscriptions-frontend

- Дата: `2026-04-24 11:48`
- Статус: `Готово`

## Краткое описание задачи

Полностью отключить фронтовые запросы подписок, так как фича временно выключена.

## Что сделано

- В `frontend/src/hooks/use-subscriptions.ts` отключён любой сетевой запрос подписок.
- `loadSubscriptions()` теперь:
  - не вызывает API
  - просто выставляет пустой список подписок

## Что это меняет

- Больше не вызывается ни:
  - `/api/subscriptions`
  - ни `/api/conversations/:id/subscriptions`

## Валидация

- Сборка не запускалась по прямому указанию пользователя.
