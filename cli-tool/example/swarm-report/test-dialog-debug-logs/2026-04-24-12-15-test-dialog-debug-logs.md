# Отчёт: test-dialog-debug-logs

- Дата: `2026-04-24 12:15`
- Статус: `Готово`

## Краткое описание задачи

Добавить диагностические клиентские логи для автопрогона тестового диалога, чтобы локализовать причину, по которой после первого сообщения не стартует следующее.

## Что добавлено

В `frontend/src/components/chat/chat-layout.tsx` добавлены `console.debug` с префиксом:

`[test-dialog]`

Логи покрывают:

- старт автопрогона
- blocked-start, если кнопка не может сработать
- получение `pipeline completed`
- пропуск повторной обработки того же `messageId`
- выбор `nextMessage`
- `pipeline.reset()` после completion
- фактический автозапуск следующего сообщения
- завершение всей очереди
- остановку на `failed`
- снимок текущего состояния очереди и pipeline

## Валидация

- Сборка не запускалась по прямому указанию пользователя.
