# Фича: Режим тестирования контекстных стратегий

**Дата:** 2026-03-29

## Описание задачи

Новый режим "Тестирование" для генерации диалогов AI-за-обе-стороны с расширенной debug-информацией по стратегиям контекста.

## Итоги Research

Консилиум из 4 агентов провел анализ:
- **Архитектор:** Разработка интеграции SSE стриминга с существующей архитектурой chat.service
- **Фронтенд-эксперт:** Компоненты для UI теста, хук для SSE, интеграция в chat-layout
- **API-дизайнер:** Контракт SSE endpoint POST /chat/test-dialogue, DTO для параметров
- **UI-дизайнер:** Форма ввода, прогресс-бар, debug-панель с debug-информацией

Ключевые решения:
- SSE для стриминга результатов генерации в реальном времени
- Переиспользование sendMessage внутри цикла генерации пар диалогов
- Флаг is_test в conversations + таблица message_debug_data для хранения debug-метаданных

## План реализации

1. **Backend:** Добавить DTO, миграции БД, SSE endpoint, debug-логику в стратегии
2. **Frontend:** Компоненты формы/прогресса/debug-панели, хук SSE, интеграция в UI
3. **БД:** 2 миграции (таблица + поля)
4. **Validation:** TypeScript, build, базовая проверка корректности

## Что реализовано

### Backend

**Новые файлы:**
- `backend/src/chat/dto/test-dialogue.dto.ts` — DTO для тестового диалога (topic, pairsCount, params, simulatorModel)

**Модифицированные файлы:**
- `backend/src/database/database.service.ts` — миграции 008 (is_test, test_topic, test_pairs_target) и 009 (message_debug_data таблица)
- `backend/src/chat/chat.service.ts` — метод generateTestDialogue с SSE streaming, sendMessage возвращает assistantMessageId
- `backend/src/chat/chat.controller.ts` — SSE endpoint POST /chat/test-dialogue
- Все 3 стратегии контекста — verbose debug metadata (originalMessagesCount, keptMessagesCount, budgetMax/Used, factsSnapshot, branchInfo)
- `backend/src/conversation/conversation.service.ts` — create() с isTest/testTopic, saveDebugData(), getDebugDataForConversation(), findOne() с debug-данными
- `backend/src/conversation/dto/create-conversation.dto.ts` — isTest, testTopic поля
- `backend/src/conversation/conversation.controller.ts` — прокидка isTest/testTopic параметров
- `backend/src/chat/dto/ai-params.dto.ts` — contextStrategy, strategyParams поля

### Frontend

**Новые файлы:**
- `frontend/app/components/test-setup-form.tsx` — форма ввода (тема диалога + slider длины + кнопка "Сгенерировать")
- `frontend/app/components/test-progress-bar.tsx` — прогресс-бар + кнопка "Остановить"
- `frontend/app/components/debug-panel.tsx` — collapsible debug-панель (стратегия, token breakdown, strategy details)
- `frontend/app/hooks/use-test-dialogue.ts` — хук SSE-стриминга (isGenerating, progress, messages, abort)

**Модифицированные файлы:**
- `frontend/app/types/conversation.ts` — MessageDebugData интерфейс, isTest в Conversation
- `frontend/app/types/ai-params.ts` — TestDialogueParams, TestDialogueEvent интерфейсы
- `frontend/app/lib/api.ts` — startTestDialogue() с SSE fetch для стриминга результатов
- `frontend/app/hooks/use-chat.ts` — debugData, isTestGenerated в Message интерфейсе
- `frontend/app/components/chat-layout.tsx` — переключатель Чат/Тест режимов, интеграция useTestDialogue
- `frontend/app/components/message-bubble.tsx` — debugData prop, приглушённый стиль для сгенерированных user-сообщений, DebugPanel компонент
- `frontend/app/components/conversation-sidebar.tsx` — TEST badge для тестовых conversations, отображение testTopic
