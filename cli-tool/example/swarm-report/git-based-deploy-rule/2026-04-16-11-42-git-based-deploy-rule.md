# Отчёт: правило git-based деплоя

## Задача

Зафиксировать в проектных правилах, что деплой нужно выполнять через Git, а не
через прямую синхронизацию файлов на сервер.

## Что реализовано

- В `AGENTS.md` добавлен раздел `Деплой`
- Зафиксировано, что источник истины для деплоя — skill
  `.agents/plugins/plugins/first-lesson-local/skills/deploy/SKILL.md`
- Зафиксировано, что по умолчанию используется только git-based деплой по
  правилам этого skill
- Зафиксирован запрет на обычный деплой через `rsync`, `scp` и другие способы
  ручной заливки файлов

## Проверка

- Перечитан изменённый фрагмент `AGENTS.md`
- `git diff --check`

## Ограничения и допущения

- Изменение фиксирует проектное правило и не выполняет деплой само по себе
